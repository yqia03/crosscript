## 2. 已识别且无法由历史真实证据替代的新边界

所有新服务调用、上传和联网冷准备都须把本节与第3节的实际限制合并后一次确认。历史预算不结转。未确认之前新增真实请求为0。

### T：DeepSeek 多行普通文本合同

2026-10-21 的现实现默认非流式；当普通文本包含换行时，`PlainTextTranslationLayout` 将非空行编码成含ID的JSONL，并要求按ID返回译文。历史非流式普通文本是直接正文，不能证明模型遵循此新格式。无换行普通文本仍走直接译文合同，可以复用历史JSON证据。Markdown走自身结构合同，不因这个plain变化要求新云请求。

T1/T2：英文→简中、简中→英文各一份自写多行普通文本，每份UTF-8≤1KiB、最多8行，含空行、连续空行、重复行、尾部换行；各一次明确提交，最多2个逻辑请求/2个HTTP，无重试或服务切换。获准后检查目标语言可读、ID准确关联、显式换行/空行保留，以及编辑、导出、历史重开/旧快照。每份2分钟观察截止，超时主动停止并不派发下一项；保存部分结果和已知/未知使用量。

拟预留新DeepSeek执行预算US$0.02。当前实际App构造`OpenAITextTranslator()`，`maxOutputTokens`默认未设置，页面没有现成输出token额度入口；源代码可注入该参数不等于最终候选已经带额度闸门。采用2请求、短输入与2分钟观察/主动停止的明确执行预算，不能保证供应商账单硬封顶。一次确认时直接说明并请求批准这一真实能力范围，不为普通验收新增产品功能。不得在聊天/计划中复制实际Key，也不临场改账户、支付方式或换模型。

### A：AiHubMix 简体中文独立证据

要求仍为独立英文、简中语音及长文件；不能因为现有精确证据以英文为主，就把支持范围改成英文。T5约1.5小时用户验收仍保留，但缺精确模型/语言，不能填补该缺口。

先定位既有独立简中来源元数据；找到精确且适用的真实证据即复用，不执行A1。若仍没有，A1仅为主模型`whisper-large-v3`准备一份自写简中编号句合成音频，≤30秒、16kHz单声道PCM16，离线预检恰好1个分片；一次明确提交、最多1HTTP、`verbose_json`及`segment`时间。新上传总≤30秒，不再跑英文或长文件，也不为版本/导出再收费重转写。

输入需预标少量段首，实际核对全文/可用段时间和段落回听，记录误差、缺词/缺时间；版本/旧编辑/导出/重开使用同一结果配合隔离fixture。拟预留US$0.01；3分钟观察后取消。当前适配器请求失败退出顺序循环、无自动重试且拒绝重定向；只发一个片可避免失败后继续下一块。预算仍不是平台硬限额，取消不能撤回已经上传或已经计费的请求。若数据不满足单片或当前模型价格使预留不足，则停止并把具体差异加入确认清单，不能扩大时长/请求。

### G：Gemini 双向质量、真实会话边界、恢复及文件补齐

固定官方`https://generativelanguage.googleapis.com/v1beta`，Live模型`gemini-3.5-live-translate-preview`，独立文件模型`gemini-3.5-flash-lite`。两者共用官方目标凭据作用域，不把Live能力推给文件模型，不借其他服务密钥。保留英文↔简中要求；英文→简中长会话不能替代历史未通过的简中→英文质量。

- **G1长会话：** 一份自写英文编号句合成音源，每30秒不同编号，含开始、边界前后、断线时、恢复后及最后一句标记，真实专用应用系统音频采集；英→简中。一个本地连续会话计划16分钟，停止目标≤16分10秒。最多3连接：初始1次、自然边界后显式重连最多1次、可控断线后显式重连最多1次。每次结束协议静音最多4秒，最多12秒，另记于上传、不写入原音频。用户操作或观察失败就不派发下一连接。
- **边界解释：** Google专用翻译文档未给出此模型单独时限；通用无压缩audio-only会话15分钟、连接约10分钟的说明只能作为观察依据，不能冒称本模型必在精确时刻重置。当前setup没有压缩/会话恢复。第一连接保留至真实关闭/GoAway或计划终点，不为规避边界频繁重置；未观察到真实边界则记证据不足，不延长会话、不把16分钟本地录音写成16分钟同一云连接通过。[Google会话说明](https://ai.google.dev/gemini-api/docs/live-api/session-management)、[专用翻译说明](https://ai.google.dev/gemini-api/docs/live-api/live-translate)。
- **G1断网：** 自然边界恢复后，或未观察到边界时接近计划末段，只执行一次30秒可控网络中断，随后一次显式重连。断网范围限专用测试环境/连接，不影响用户生产网络、其他任务或远程控制；不能隔离则停止此步并记录未执行。检查本地音频连续、缺口、恢复首先出现新编号，区分实际断网与仅关闭WebSocket。
- **G2反向质量：** 另一次自写简中编号句≤30秒原始输入、简中→英文、最多1连接，结束协议静音≤4秒。检查原文关键语义、译文完整性及末句；不能只凭末词返回判质量通过。观察截止≤90秒，不重试。两轮Live合计最多4连接、原媒体≤16分40秒，协议静音单列合计≤16秒；云输出音频即使丢弃仍可能收费。
- **G1结束后补齐：** 只对G1录音明确提交一次补齐任务。现媒体确认边界保守，缺口可能覆盖全段原/译两通道；≤16分10秒完整连续两通道时按每片≤60秒为17片×2＝34个`generateContent`请求；多个不连续缺口须逐区间分别向上取整，可能超过34。批准上限仍为34请求、累计音频≤32分20秒，不是“30秒缺口两请求”。先只读预检每个通道每个缺口的实际分片总和及输入长度；超过34片就不提交，不改写缺口或伪造锚点来省请求。现请求`candidateCount=1`、`maxOutputTokens=4096`、`MINIMAL`；每片只尝试一次，任务墙钟≤10分钟，到时取消且不恢复。G2不新增第二个补齐任务。
- **保存与结果：** 检查原音频、新旧结果、旧编辑、待补齐区间、已有成功片、重开和导出。没有可靠段落锚点时补齐会附加带区间说明内容，不能预先保证零重复或精确插回原自然段；实际出现阻碍既定用户行为的问题按相关任务最小修复后再回候选判定。

Google拟申请新预算合计US$2：Live US$1.25（包含G1/G2及至多4连接）、文件US$0.50、缺usage/尾段/估算误差US$0.25。这个金额不是旧预算、不是供应商承诺的最大账单。执行前按相同精确模型核对当前[Google价格](https://ai.google.dev/gemini-api/docs/pricing)，预留最大可解释费用，价格或输出估算无法控制在申请范围就不启动；不隐式把未用预留转给其他服务。

## 3. 停止能力必须与实际实现一致

每项均先做离线预检，确认本次操作的时钟/请求计数可记录，操作者或测试监控能及时调用实际停止/取消，并确认本次采集和连接确实结束；本方案没有创建或验证新的自动看门狗。失去停止能力、目标不符、身份/资料异常、认证/额度/模型失败、已知费用接近预留或硬截止时，不开始后续任务。取消后应记录已发出及在途动作，不声称收回云端处理或费用。

当前Gemini文件补齐会对凭据、额度、配置、模型、不可用、限流及请求限额错误停止循环；普通`.processing`等单片错误可能继续未完成片。操作者看到错误后可取消，但下一片可能已发出，仍计入最多34次范围。因此不能承诺“任何首错后精确0个后续请求”。执行计划采用当前真实能力：已列类别自动停止，普通单片错误一经观察立即取消/不派发新任务，已经在途的下一片仍计入34次总范围；把该语义直接纳入一次确认，不口头承诺精确首错零后续请求。本方案不要求新增产品功能来制造更严格的守卫。

当前App没有跨任务的供应商账单硬闸门；时长/次数/token局部限制也不保证最终扣费。缺usage保守预留，不当零；周期usage不随意累加、去重或取最后值冒充账单。次数、短输入、观察时限和取消机制构成这次需要用户批准的执行预算；如实记录在途和已计费动作，不新增账户级硬闸门。不得为布置控制擅自读取账单、管理Key或改变付款设置。

## 4. I：最终普通Mac安装及HTTPS冷准备

同一最终候选，在普通Apple Silicon Mac的干净、受控非开发环境进行；记录设备、系统版本、隔离方式及是否有系统级开发工具。可以是同一物理Mac的合适受控环境，不强制另购/另备第二台机器；单独新建App资料目录不等于非开发环境。实际采用的环境需在统一确认前填定；创建用户/系统卷等系统更改不包含在本稿的执行授权里。

采用标准Finder安装和系统允许的未公证App打开方式；保留quarantine，不全局关闭Gatekeeper/SIP、不清除隔离属性、不重签下载包。先退出旧App、仅移除旧App包、保留资料/偏好/Keychain身份；旧资料升级只用独立合成fixture和假凭据，不读取真实用户资料/Keychain或迁移实际密钥。麦克风、系统声音必要权限各≤10秒本地短采集，停止、保存/重开，不上传。

一次真正HTTPS PDF冷准备，≤30分钟观察后取消；不复制缓存、不手动预装Python/Homebrew或预置runtime、不继承旧PDF资源/Downloads/assets/PYTHONPATH。当前manifest为`babeldoc-0.6.4-py312-20261029-arm64-crosscript-v3`：267个实际artifact，其中245个HTTPS artifact预期内容359,471,768 bytes，22个bundle artifact共232,795,324 bytes。artifact数量不是实际网络事务数，重定向/失败/传输开销另计；originArtifact来源不是当前下载项。

只允许当前manifest所需HTTPS和必要HTTPS重定向，不扩到个人文档下载。校验失败、准备失败或超时即取消，不重试。App没有全局接收字节硬闸门，不能把预期内容bytes或建议500MB观察阈值写成可靠流量硬上限。模型费用US$0，网络流量费用不包含在模型预算内。成功后再次打开准备入口只复用缓存，不再次远程下载；用非私有本地PDF/已有隔离结果验证环境可用、阅读、保存/重开，不新增DeepSeek请求。
