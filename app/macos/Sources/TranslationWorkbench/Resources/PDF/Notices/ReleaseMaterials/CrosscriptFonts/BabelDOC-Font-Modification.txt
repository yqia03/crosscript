This is a modified build of BabelDOC 0.6.4. It is not an upstream release.
Package METADATA Version remains 0.6.4; the wheel build tag distinguishes it.
Original BabelDOC metadata, dependency requirements, entry points and AGPL license
text are retained unchanged. See licenses/LICENSE in this dist-info directory.
Crosscript-authored integration modifications and the packaging helper are
AGPL-3.0-only. This notice does not replace the original license or attribution.

Changes are limited to the two Python source modules listed below, WHEEL Build,
this notice and regenerated RECORD. The font registry uses the twenty approved
Crosscript CJK Sans/Serif CN/HK/JP/KR/TW Regular/Bold identity-only derivatives,
with exact file names, sizes and SHA3-256 values. Missing or corrupt local
derivatives fail before upstream font download, requiring repair of the pinned
runtime. The original fourteen other font entries and family selection order
remain unchanged. The TTF files are supplied separately and retain OFL-1.1;
this wheel contains no renamed TTF payloads.

Preferred form for modification: the Python .py files in this wheel and the
accompanying complete changed sources, unified patches and reproducible
build_babeldoc_wheel.py helper identified by preferred-source-index.json.
