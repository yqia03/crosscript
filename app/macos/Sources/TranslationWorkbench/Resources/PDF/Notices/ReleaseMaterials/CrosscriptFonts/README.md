# Current Crosscript font notices

The current runtime contains 20 Crosscript CJK identity derivatives and 14 unchanged upstream fonts. `NOTICE.md` preserves the dated modification notice; complete original OFL texts are in `licenses/`. `BabelDOC-Font-Modification.txt` identifies the matching registry wheel modification.

`provenance-index.json` and `font-identity-map.json` identify exact conversion inputs, Adobe references and renamed outputs. Their `derivatives/`, `tools/` and `wheel/` paths are relative to `current/fonts/` in the companion **Crosscript-third-party-0.1.0-5-materials-v4.tar.gz**, not to this compact App notice directory. That companion contains full editable changes, reproducible scripts and bounded offline test evidence. The App payloads themselves are in `PDF/Bundled/` and bound by `runtime-manifest.json` / `bundled-runtime-index.json`.

Source/archive availability in a local review candidate is not public release authorization or another-Mac installation acceptance. Original font licenses and all attribution remain intact; no old-identity converted TTF or converter ZIP is bundled here.
